## S3 Transfer Acceleration

アップロードを高速化する機能

出典: [Using Amazon S3 Transfer Acceleration to Accelerate Geographically Disparate Data Transfers](https://docs.aws.amazon.com/whitepapers/latest/s3-optimizing-performance-best-practices/using-amazon-s3-transfer-acceleration-to-accelerate-geographically-disparate-data-transfers.html)
> "Amazon S3 Transfer Acceleration is a service offered by AWS that minimizes or eliminates latency caused by geographic distance between clients and regional applications using Amazon S3. It utilizes the globally distributed edge locations in CloudFront for data transport."

CloudFront のエッジロケーションを経由してアップロードすることで、遠距離からのアップロードを高速化する

### ユースケース

- 遠距離からの大容量ファイルアップロード
- グローバルに分散したクライアントからのアップロード
