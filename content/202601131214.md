# Enterprise

### [Enterprise Cloud と Enterprise Serverの併用](https://docs.github.com/ja/enterprise-cloud@latest/billing/concepts/enterprise-billing/combined-enterprise-use#about-licensing-models)

GitHub Enterprise プランでは、GitHub Enterprise Cloud と GitHub Enterprise Server の両方を使用できる

※ Enterprise Cloud、Enterprise Server の両方を使用する場合、Enterprise アカウントがそれぞれに存在することになる

※ Enterprise プランにおける GitHub Enterprise Cloud のデプロイは、GitHub.com もしくはGHE.com のいずれか一回のみ

※※ GitHub.com
- 標準のGitHubプラットフォーム。米国でデータを保存する

※※ GHE.com
- [GitHub Enterprise Cloud with data residency](https://docs.github.com/ja/enterprise-cloud@latest/admin/data-residency/about-github-enterprise-cloud-with-data-residency)の専用プラットフォーム
- データ保存場所を選択可能（EU、オーストラリア、米国、日本）

### [Enterprise アカウント](https://docs.github.com/ja/enterprise-cloud@latest/admin/concepts/enterprise-fundamentals/enterprise-accounts)

複数の Organization の作成し管理できる。

例えば、Enterprise name/Enterprise URL slugを以下のように設定した場合、Enterpriseアカウントの管理コンソールに以下のURLでアクセスできる

- Enterprise URL slug: test-ent
- Enterprise アカウント管理コンソール: https://github.com/enterprises/test-ent


[GitHub Enterprise の課金 - GitHub Enterprise Cloud Docs](https://docs.github.com/ja/enterprise-cloud@latest/billing/concepts/enterprise-billing/billing-for-enterprises)

GitHub Enterprise ライセンスには、使用量ベースとボリュームの 2 つの課金モデルがある

- 使用量ベース: 2024年8月1日以降の契約についてはこちら
- ボリューム契約: 契約の有効期限が切れるまでこの方法が使用される

### 使用量ベースの課金について

[Enterprise ライセンスの使用量ベースの課金 - GitHub Enterprise Cloud Docs](https://docs.github.com/ja/enterprise-cloud@latest/billing/concepts/enterprise-billing/usage-based-licenses)

[GitHub Enterprise クラウドとサーバーの併用 - GitHub Enterprise Cloud Docs](https://docs.github.com/ja/enterprise-cloud@latest/billing/concepts/enterprise-billing/combined-enterprise-use#usage-based-and-volume-licensing)

Enterprise アカウントのOrganizations に所属するアクティブユーザー数に応じて請求が行われる。

詳細はEnterprise アカウントの billing and licensing > Licensing > Enterprise Cloud > Consumed lisences から確認可能。
