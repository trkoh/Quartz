[GitHub アカウントの種類 - GitHub ドキュメント](https://docs.github.com/ja/get-started/learning-about-github/types-of-github-accounts)

3種類ある。

- ユーザー アカウント
- Organization アカウント ^e57d08
- Enterprise アカウント

# ユーザーアカウント

GitHub を使用するすべてのユーザーは、ユーザーアカウントにサインインすることになる

ユーザーアカウントには以下の2種類が存在する

- 個人用アカウント ^825a7a
- マネージドユーザーアカウント

### 個人用アカウント

GitHub.comでサインアップした場合、個人アカウントが作成される。

また、プラン的には GitHub Free またはGitHub Pro のどちらかを使用することになる

### マネージドユーザーアカウント

GitHub Enterprise Cloud の Enterprise でサインアップした場合、マネージド ユーザー アカウントが使用される

# Organization アカウント

多数の人が多くのプロジェクトで同時にコラボレーションできる**共有アカウント**。

Organization アカウントに**サインインすることはできない**。

各ユーザーは Organization のメンバーとなり、与えられたロールの権限のもと操作が可能。

その上で、利用者はそれぞれのユーザーアカウントでログイン後、各自がOrganization のリソースに対して操作を行う。

# Enterprise アカウント

GitHub Enterprise Cloud と GitHub Enterprise Server では Enterprise アカウントが使用できる

管理者が複数の Organization のポリシーと課金を一元的に管理し、Organization 間の内部管理が可能に

詳細は[エンタープライズ アカウント](https://docs.github.com/ja/enterprise-cloud@latest/admin/concepts/enterprise-fundamentals/enterprise-accounts)
