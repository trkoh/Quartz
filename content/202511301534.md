# メモ

- ちょっと長めの指示する時
	- `/editor`
- Kiro の回答を引用しつつ指示する時
	- `/reply`
- 別な内容について質問したい時
	- `/tangent` もしくは `Control + T`
- コンテキストとして読み込まれているファイルを確認したいとき
	- `/context show`
- agentを切り替えたい時
	- `/agent list`
	- `/agent swap <agent name>`
- 改行したいとき
	- `Control + j`
