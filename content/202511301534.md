# メモ

- ちょっと長めの指示する時
	- `/editor`
- Kiro の回答を引用しつつ指示する時
	- `/reply`
- 別な内容について質問したい時
	- `/tangent` もしくは `Control + T`
- コンテキストとして読み込まれているファイルを確認したいとき
	- `/context show`
- agentを切り替えたい時
	- `/agent list`
	- `/agent swap <agent name>`
- 改行したいとき
	- `Control + j`

## /prompts

- 使用できるプロンプトを確認
```
/prompts list
```

- プロンプトを編集
```
/prompts edit <プロンプト名>
```

- プロンプトを使用
```
// プロンプトとして保存した内容をコンテキストに入力
@<プロンプト名>
```

- プロンプト作成
```
/prompts create --name <プロンプト名>
```
